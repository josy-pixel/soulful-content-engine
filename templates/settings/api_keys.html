What these keys are for

A client's scenario uses its own key to report back to this app — that a post went live, and how it performed. The key identifies which client is calling, so a scenario can only ever touch that client's own posts.

No key publishes anything. Content arriving from outside would land as needs review; releasing it stays a human decision in this app.
